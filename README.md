## About this repository

This is a mirror of the theme's source, published from the Blocklane monorepo by `bin/publish-theme-source.sh` for every release; one commit per version, tagged. Issues and pull requests are welcome here: changes land in the monorepo, so a pull request is ported there, tested, credited in the changelog, and closed once the port ships (see CONTRIBUTING). Security reports go through the Security tab, "Report a vulnerability".
